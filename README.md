# gomesh-broker

> **Work in progress**

An MQTT broker for the Bay Area [MeshCore](https://github.com/ripplebiz/MeshCore) community, written in Rust. Handles authentication, authorization, and message filtering for MeshCore mesh network nodes.

Built on [rmqtt](https://github.com/rmqtt/rmqtt) with Ed25519 JWT auth for publishers and role-based access control for subscribers.

## Status

This project is under active development and not yet ready for production use.
